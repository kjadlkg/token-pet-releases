# token-pet-releases

Downloads and skin data for token-pet, a pixel pet for Windows that shows your Claude Code usage.

## 받기

[Releases](https://github.com/kjadlkg/token-pet-releases/releases/latest)에서 `token-pet.exe`를 받아 실행한다. 설치 과정은 없다.

처음 실행할 때 Windows가 "알 수 없는 게시자" 경고를 보이면 "추가 정보"를 누른 뒤 "실행"을 누른다.

## 새 버전으로 바꾸기

새 버전이 나오면 크로냥이 말풍선으로 알려 주고, 우클릭 메뉴 맨 위에 "새 버전 받기"가 생긴다. 새 `token-pet.exe`를 받아서 쓰던 파일을 바꾸면 된다.

## skins.json

앱이 받아 가는 스킨 목록이다. 앱은 켜고 10초 뒤, 그 뒤로 6시간마다 이 파일을 확인해서 새 스킨을 메뉴에 넣는다. 우클릭 메뉴의 "새 스킨 자동으로 받기"로 끌 수 있다.

앱은 이 파일을 받기만 하고, PC 정보나 사용량을 어디로도 보내지 않는다.
