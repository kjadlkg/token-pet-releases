## 시작하기

1. [최신 버전 받기](https://github.com/kjadlkg/token-pet-releases/releases/latest)에서 `token-pet.exe`를 내려받아요.
2. 받은 파일을 실행해요.
3. 크로냥을 우클릭하고 **사용량 연결**을 눌러요.

이제 Claude Code를 쓰면 사용량이 표시돼요.

> [!TIP]
> 처음 실행할 때 "알 수 없는 게시자" 경고가 뜨면 **추가 정보**를 누른 다음 **실행**을 눌러 주세요.

## 기능

| 기능 | 설명 |
|---|---|
| **사용량 확인** | 5시간 한도와 주간 한도를 말풍선으로 알려 줘요. 크로냥을 누르면 자세한 패널이 열려요. |
| **세션 친구** | Claude Code 세션마다 병아리가 한 마리씩 나타나요. 일하는 중인지 쉬는 중인지 모습으로 알 수 있어요. |
| **입력 대기 알림** | 세션이 입력을 기다리면 병아리 머리 위에 `!`가 떠요. 누르면 그 창이 앞으로 나와요. |
| **꾸미기** | 스킨, 배경, 계절마다 바뀌는 바닥 장식, 울타리를 고를 수 있어요. |
| **자리 옮기기** | 크로냥을 잡아서 원하는 곳에 내려놓을 수 있어요. 어느 모니터에 둘지도 고를 수 있어요. |

모든 설정은 **크로냥을 우클릭**하면 나오는 메뉴에 있어요.

## 업데이트

| 종류 | 받는 방법 |
|---|---|
| **스킨** | 자동으로 받아 와요. 새 스킨은 메뉴의 "스킨"에 저절로 추가돼요. |
| **새 버전** | 크로냥이 말풍선으로 알려 드려요. 메뉴 맨 위의 "새 버전 받기"로 새 파일을 받아, 쓰던 파일과 바꿔 주세요. |

자동으로 받는 게 싫다면 메뉴에서 "새 스킨 자동으로 받기"를 꺼 주세요.

## 개인정보

> [!NOTE]
> token-pet은 PC 정보나 사용량을 **어디로도 보내지 않아요.**
> 인터넷으로 하는 일은 이 저장소의 스킨 목록(`skins.json`)을 받아 오는 것뿐이에요.

## 그만 쓰고 싶을 때

1. 우클릭 메뉴에서 **사용량 연결 해제**를 눌러요.
2. **종료**를 눌러요.
3. `token-pet.exe`를 지워요.
